lzssh
Source Download for Windows

Your SSH hosts, keys and security keys in one small Windows app.

Save hosts in folders, keep passwords and keys in a PIN-encrypted vault, and connect in Windows Terminal with one click. A YubiKey or Windows Hello works through the native Windows dialog.

Try it here. The demo PIN is 123456. Double-click a host to connect, or press Ctrl+Alt+P for the password picker.

Runs entirely in this page. Nothing is stored or sent.

What it does

Hosts and folders
Name, IPv4 or IPv6 address, port and user, grouped in folders. Sessions open in Windows Terminal through the built-in Windows OpenSSH client.
A vault for secrets
Passwords, private keys and FIDO key handles, encrypted with a PIN of 6 to 256 digits (Argon2id and XChaCha20-Poly1305), then wrapped with Windows DPAPI.
Quick unlock
Unlock with Windows Hello or a FIDO2 security key instead of typing the PIN. The PIN always keeps working.
Security keys
Create ed25519-sk or ecdsa-sk keys in the Windows security key dialog. Logging in takes one touch.
Passwords without typing
Press Ctrl+Alt+P anywhere, pick a password, paste it. The clipboard is cleared after 90 seconds.
Keys onto servers
Append a public key to ~/.ssh/authorized_keys on a host, and clean up known_hosts without a text editor.

Moving hosts to another PC

Two installs can pair and send folders and secrets to each other. Everything is encrypted for the receiving device before it leaves your PC.

  1. Pair. One device shows a code, the other enters it within 10 minutes.
  2. Send. Pick the folders and secrets, then the device to send them to.
  3. Pick up. The other device collects and decrypts them the next time lzssh is unlocked there.

This page runs on a sync server

The same Cloudflare Worker that serves this page holds the mailboxes under /v1/. Every request needs the access token and a signature from the device key, and the Worker only ever stores ciphertext. To run your own, deploy the worker/ folder: 

cd worker && pnpm install
pnpm wrangler secret put ACCESS_TOKEN
pnpm wrangler deploy
